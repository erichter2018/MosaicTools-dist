Fix Layout (beta)

Arranges InteleViewer's panes, series and window/level from your saved hanging protocols, by a click or automatically on every study.

Stage and pane-rule repairs

Stage editing and saving keep the edited stages together, and pane preferred-series rules follow their series attributes. Safer layout changes avoid leaving InteleViewer unable to open the next study. Pane fallbacks, including an empty pane when the required prior is absent, use the saved stage rules.

What it does

Fix Layout is a small always-on-top window that sets up InteleViewer for the study you open. From a saved hanging protocol it chooses the grid, which series and priors go in which pane, the first image, fit or fill, and the window/level.

It matches protocols by modality and body part (CT, MRI, X-ray and ultrasound) and by how many priors are loaded. One protocol can cover several body parts.

How to turn it on / set it up

  1. In Settings → Keys & Buttons, under InteleViewer Buttons, check Start Fix Layout with MosaicTools (beta).
  2. MosaicTools starts the Fix Layout window within about 30 seconds. If InteleViewer is not open yet, it starts once InteleViewer opens.
  3. In the Fix Layout window, build or edit your protocols. Tick Auto-fix if you want every new study arranged without a click.

InteleViewer 5-8-1-P389 is preferred. Fix Layout checks the exact InteleViewer build before it connects, and it refuses to start on a build it does not know. It is not guaranteed to work with any other InteleViewer version.

Using it

  • Fix arranges the current study now. Auto-fix does it on every study change and fills panes as late series arrive.
  • If a protocol has several stages, they show as small blue boxes above Auto-fix; the current stage is outlined in green.
  • Use this protocol in the editor applies a protocol to the current study even if it would not normally match.
  • Auto-fix does not move a pane you are already scrolling. (since 6.4.1)
  • Mini view shrinks the window to a small bar. Stages can be picked, added and renamed. (since 6.4.1)
  • The series used when the primary series is missing has its own full settings. (since 6.4.1)
  • Pane locks keep a pane as you set it. Scrolling after the first arrangement does not re-centre the images.
  • Saving a protocol is refused while two protocols would both be the default for the same body part; a light-red warning names the conflict.

Good to know

  • Fix Layout runs its own code inside InteleViewer to change the viewer. It does not change InteleViewer's files or settings, and it sends nothing to the PACS. Security software on some PCs may block it; then it does not start.
  • Your protocols stay in %LOCALAPPDATA%\MosaicTools\LayoutManager\ and survive MosaicTools updates. A sanitized backup copy goes to your OneDrive.
  • If you close the Fix Layout window, MosaicTools does not reopen it until you turn the setting off and on, or restart MosaicTools.
  • MosaicTools updates Fix Layout together with itself. A busy Fix Layout (an editor open, a layout in progress) is never forced closed; the update waits for it.

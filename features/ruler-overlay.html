Draggable Ruler Overlay

Puts a draggable, calibrated copy of InteleViewer's ruler on screen — drag it onto anything to measure, release and it snaps back home.

What it does

InteleViewer draws its scale bars at the edges of the viewport, which is exactly where the finding isn't. This feature captures both the vertical and horizontal rulers, re-renders them as transparent always-on-top overlays sitting on the real scale bars, and makes them draggable: grab one, drag it over the structure you want to measure, read the tick marks, release — it snaps back to its home position.

How to turn it on / set it up

Settings → Keys & Buttons → InteleViewer Buttons → check Show draggable ruler overlay. No action mapping needed; the overlays appear whenever InteleViewer's rulers are visible.

Using it

  • The overlays sit invisibly on top of InteleViewer's own rulers until you need them — drag to measure, release to snap back.
  • The overlay watches the underlying pixels and recaptures itself automatically when the ruler changes (new zoom level, new series, window/level change), so what you drag around is always the ruler that matches the current image scale.
  • The rulers hide promptly when you switch to another app or minimize InteleViewer, and reappear when you come back.

Tips & gotchas

  • Because the overlay is a calibrated copy of the actual scale bar, it's only as current as the last recapture — after a zoom change give it a beat (it re-checks about every 1.5 s) before trusting a borderline measurement.
  • Works with both yellow and orange InteleViewer ruler colors.
  • Measurement text and annotations near the ruler are excluded from capture, so annotations don't get misread as tick marks.
  • For a lesion you want an actual number pasted for, Auto Measure is usually faster — the ruler overlay shines for quick "is this about a centimeter?" checks.

Critical Findings

One button press scrapes the Clario exam note, formats the critical-communication details (who, when), and pastes a ready-made documentation line into your Mosaic report.

What it does

When a study has a critical-communication note in Clario, this action reads the exam note directly from Clario, extracts the contact name and time, formats them into your documentation template, and pastes the result into the Mosaic report — no window switching, no retyping names and timestamps.

How to turn it on / set it up

  1. Map the Critical Findings action to a mic button or hotkey in Settings → Keys & Buttons → Open Keys Configuration...
  2. Customize the output in Settings → Text & Templates → Templates → Critical Findings. The template supports the placeholders {name}, {time}, and {date}.
  3. In Settings → Profile, set Doctor Name to your name as it appears in Clario — this filters your own notes out of the results so the pasted contact is the person you spoke to, not you.
  4. Optional: the Timezone setting in Profile converts note times to a specific timezone; (Keep original) preserves whatever the note says.

Using it

Open the study in Mosaic, press your mapped button, and the formatted line appears at the cursor. If MosaicTools created the Clario note itself (see Critical Notes), the study is also added to the session's critical-studies tracker.

Tips & gotchas

  • The scrape needs the study's exam note to actually exist in Clario; on a study with no note you'll get nothing to paste.
  • Debugging: hold the Win key while triggering the action to see the raw scraped data in a dialog. There's also right-click the bar → Debug → Copy Critical Findings Debug.
  • Works via Clario CDP when configured (instant JS reads) with UI Automation as the fallback.

Independent Column Scrolling

Keeps transcript and report scrolling separate where Mosaic exposes a supported column-level scrolling interface.

Working without external CDP

External Mosaic CDP now defaults off. With Independent column scrolling enabled, MosaicTools can route the mouse wheel to the transcript or report through Windows accessibility, but only when Mosaic exposes a scroller belonging to that field. It does not move focus or use the entire report page as a substitute scroller.

If no suitable scroller is available, normal Mosaic wheel behavior remains. Availability depends on Mosaic's accessibility support; the setting cannot create a field-level scroller that the application does not expose. This compatibility has not yet been verified live on every current Mosaic version.

Using it

Place the pointer over the field you want to scroll and use the wheel. Moving to a different study or leaving the report view invalidates the previous field targets. You do not need to enable obsolete external CDP to try the accessibility path.

This feature concerns Mosaic's report columns. It is separate from InteleViewer image-stack dragging and its scrolling fix.

Older CDP environments

Where external CDP still works, the existing column styling can provide separate transcript, report and utility scrolling. Hold the report's scroll position is a separate CDP feature; turning off independent scrolling does not turn off that guard. If an older environment repeatedly returns the report to its previous position after edits, disable the scroll-position guard separately.

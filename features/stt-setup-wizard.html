Quick Setup Wizard

A guided, one-step-at-a-time wizard that creates the speech-engine accounts, captures and validates the API keys, and assembles the recommended ensemble for you.

What it does

Setting up multi-engine dictation by hand means a half-dozen accounts, consoles, and key formats. The wizard turns that into a sequence of small steps: for each recommended engine it opens the signup page in your real browser (steering you to "Sign in with Google" so there are no new passwords), then watches your clipboard — the moment you click Copy on the provider's key page, the wizard grabs the key, validates it with a real connection to the provider, stores it, and moves on. Nothing to paste. At the end it arranges everything you set up into the current Recommended Ensemble (driver + voting secondaries in priority order).

How to turn it on / set it up

Settings → Speech-to-Text → ⚡ Quick Setup Wizard. It's safe to re-run any time; it remembers your previous answers.

Using it

Beyond the key steps, the wizard also: turns on the two prerequisites (Custom dictation and Direct Mosaic access) with one click if they're off; adds the free on-device medASR model; offers a single OpenRouter step; and switches Mosaic's "Auto Transcript Record" off so Mosaic doesn't grab the microphone first. If the recommended line-up changes in a future update, you get a one-time tip to re-run it.

The review screen at the end leads with the recommended ensemble and a simple keep-vs-switch choice; the full per-engine checklist is tucked behind an "Adjust engines" expander you open only if you want to fine-tune.

Updated in 5.9.2

The recommended line-up was re-measured across the full dictation corpus, and one long-standing flaw was corrected: the recommender could put two AssemblyAI engines in the same ensemble. Because those two hear the same audio the same way, they voted as two independent opinions when they were really one — enough to outvote your main engine. They are no longer paired.

A new engine, OpenAI GPT Transcribe, is also available through the same single OpenRouter step. It is markedly more accurate than the older OpenAI engine it replaces, it stays quiet during silence rather than transcribing room noise into a sentence, and it costs about a fifth as much.

Because the recommendation itself changed, the wizard offers the updated line-up once even if you have already run it. Accepting is optional — your current setup keeps working.

Tips & gotchas

  • One OpenRouter key replaces the old cloud-account steps. Setting up Google Chirp used to mean a Google Cloud service account, and MAI meant an Azure resource. Now a single OpenRouter key unlocks Chirp 3, Qwen-ASR and MAI 1.5 as voting engines at once — no cloud consoles. Chirp 3 via OpenRouter is the single lowest-error voter on our test corpus.
  • A rejected key blocks the Next button on purpose — the wizard tells you plainly whether the key is bad or it looks like a network problem.
  • The recommendation is the lowest word-error ensemble it can build from your engines, and it never stacks two variants of the same engine. It matches the Graphical Ensemble Builder exactly (same underlying engine).
  • On the finish step it lists any engine you set up that the recommended stack won't use, and whether leaving it idle is free (pay-per-use) or could keep charging you (e.g. an ElevenLabs monthly plan to cancel).

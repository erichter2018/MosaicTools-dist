Critical Notes

Create a Clario communication note without leaving Mosaic — including a one-press "Create Negative Critical" that documents a negative stroke read using Clario's canned message.

What it does

Two mappable actions drive Clario's communication-note workflow for you:

  • Create Critical Note — opens and submits a Clario communication note for the current study (the classic use case: documenting a stroke or other critical result call).
  • Create Negative Critical — the same flow, but it first selects the "Negative STROKE results" canned message from Clario's Default Note Messages field before submitting, documenting a negative stroke read in one press.

How to turn it on / set it up

Map Create Critical Note and/or Create Negative Critical to a mic button or hotkey in Settings → Keys & Buttons → Open Keys Configuration... No other setup is required, though the automation works best with Clario CDP configured (Settings → Experimental → Clario CDP).

Using it

With the study open, press the mapped button. MosaicTools drives Clario's note dialog, submits it, and shows a toast. If Track critical studies this session is enabled (Settings → Alerts), the study is added to the ⚠ badge on the bar so you can find it again later.

Tips & gotchas

  • Negative criticals suppress the automatic stroke note: if you've already created a negative critical on a study, the stroke-detection auto-note won't also fire on Process Report — you won't end up with contradictory notes.
  • Create Negative Critical was added in 5.5.0; make sure the "Negative STROKE results" canned message exists in your Clario Default Note Messages, since the action selects it by name.
  • These actions pair naturally with Stroke Detection, which can create the (positive) note for you automatically or on a click of the purple alert.

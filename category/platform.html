Setup & Platform

Install, updates, button mapping, integrations, and exactly what telemetry does (and doesn't) leave your machine.

⚙️ Setup & Platformsince 4.0

CDP Integration

Reads Mosaic and Clario through the Chrome DevTools Protocol instead of screen-level UI Automation — faster, more reliable, and the foundation for the in-editor visual features.
⚙️ Setup & Platformin developmentsince 2.8

Connectivity Monitor

Four tiny status dots on the bar — Mirth, Mosaic, Clario, InteleViewer — so when things feel slow you can see in one glance whether it's the network or you. In development — not functional yet.
⚙️ Setup & Platformsince 5.1

Diagnostics & Data Sharing

Two opt-in sharing switches — app diagnostics and de-identified dictation — that let bugs get fixed remotely. Everything is scrubbed on your machine before upload, and nothing identifiable ever leaves it.
⚙️ Setup & Platformsince 2.1

Headless Mode

Launch with -headless and MosaicTools runs invisibly from the system tray — no widget bar, no hotkeys, but your mic buttons and toasts still work.
⚙️ Setup & Platformsince 2.2

Installation & Updates

A single exe with no installer and no admin rights, which quietly keeps itself up to date — updates stage in the background and apply only when it's safe, with a What's New popup and one-click rollback.
⚙️ Setup & Platformsince 2.1

Keys & Buttons

Map any MosaicTools action to a PowerMic button, a SpeechMike button, or a global keyboard hotkey — every action, one dialog.
⚙️ Setup & Platformsince 5.1

Mosaic Zoom Memory

Mosaic forgets your Ctrl+scroll text-size zoom on every launch; MosaicTools remembers it and re-applies it silently.
⚙️ Setup & Platformsince 2.1

Settings Window

One settings window for everything — sidebar navigation by topic, a live search box that filters every option, and full backup/restore of your configuration.
⚙️ Setup & Platformsince 5.1

Start with Windows

Launch MosaicTools automatically every time you log in to Windows — one checkbox, no admin rights.
⚙️ Setup & Platformsince 2.1

Widget Bar

The small always-on-top MosaicTools bar — TBWU metrics, critical-note count, STT health light, and connectivity dots at a glance, with everything else one right-click away.

Start with Windows

Launch MosaicTools automatically every time you log in to Windows — one checkbox, no admin rights.

What it does

Registers MosaicTools in the Windows startup registry so it launches on login/boot. No more remembering to start it before the first study of the shift — the bar is just there when you sit down.

How to turn it on / set it up

Check Start MosaicTools automatically when Windows starts in Settings → Profile and save. It uses the per-user startup registry key, so no admin rights are needed and it only affects your Windows account.

Using it

Log in; MosaicTools starts with your session. That's the whole feature.

Tips & gotchas

  • The checkbox reflects the registry's actual state, not a saved preference — if you disable MosaicTools under Task Manager → Startup apps (or Windows Settings → Apps → Startup), the checkbox will correctly show unchecked next time you look.
  • Saving settings refreshes the stored exe path, so if you move MosaicTools.exe to a new folder, open Settings and hit Save once to update the startup entry.
  • The auto-updater's rename trick keeps the exe path stable across updates, so startup keeps working after every update without any action from you.
  • Combine with auto-update on startup for the zero-touch experience: log in, MosaicTools starts, checks for updates, and is current before your first study.

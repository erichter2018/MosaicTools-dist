Critical Studies Tracker

A session-long list of every study you placed a critical note on, behind a red ⚠ count on the bar — double-click any entry to reopen that study in Clario.

What it does

Keeps a running list of the critical studies you've placed notes on this session. A bright red ⚠ with a count appears on the MosaicTools bar; clicking it opens a popup listing each study (patient, study, time). It answers the end-of-shift question "which criticals did I call tonight, and did I close the loop on all of them?"

How to turn it on / set it up

Check Track critical studies this session in Settings → Alerts → Critical Studies Tracker. Entries are added automatically whenever a critical note is created through MosaicTools (Create Critical Note, Create Negative Critical, stroke auto-note).

Using it

  • The ⚠ badge and count appear on the bar as soon as the first critical note is placed. Hover for the tooltip ("Critical notes placed this session — click to view").
  • Click the badge to open the list.
  • Double-click an entry to reopen that study in Clario — MosaicTools writes a small XML file into the folder Clario watches, and Clario opens the study. No searching the worklist.
  • Hover an entry and click its X to remove it from the list (e.g. once you've documented the callback).

Tips & gotchas

  • The list is session-only and memory-only — it is never written to disk, and it clears when MosaicTools exits. Treat it as a working checklist, not a permanent record.
  • When Mosaic doesn't provide a patient name for an entry, the tracker falls back to the study you're viewing in InteleViewer rather than showing "Unknown".
  • The double-click-to-open trick relies on the Clario XML watch folder existing on your workstation (standard on Fluency for Imaging installs); if Clario doesn't react, that folder may not be configured on your box.

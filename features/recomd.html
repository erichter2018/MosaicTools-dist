RecoMD Integration legacy / deprecated

Legacy integration with the external RecoMD recommendation service — superseded by the built-in MTRec engine.

What it does

RecoMD is an external best-practice recommendation service. MosaicTools can send it report data (Settings → Alerts → RecoMD integration, with an Auto-send on Process Report sub-option) and paste its recommendations back via two mappable actions, Trigger RecoMD and Paste RecoMD. Paste RecoMD deduplicates against your existing impression points, verifies the copy actually happened, and restores your mouse position.

Why it's deprecated

MTRec (5.3.0) is the in-house replacement: offline, instant, no external agent or window-scraping, with every recommendation drawn from verified guideline tables and closed with its citation. If you still have RecoMD wired to a button, the MTRec pages are where to start — enable the engine under Settings → MTRec and either use the MTRec Recommendations key or the automatic MTRec boxes after Process Report.

The RecoMD integration remains functional for workstations that still run the service (note the settings hint: it requires "Wait for Impression" to be OFF in RecoMD's own settings), but it receives no further development.

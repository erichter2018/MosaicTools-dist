Template Mismatch & Auto-Correct

A red-border alert when the loaded report template doesn't match the study type — with an optional attempt to fix it automatically by re-typing the study description into Mosaic.

What it does

Dictating a CT abdomen into a chest-radiograph template is a classic wrong-template miss. MosaicTools compares the report template Mosaic loaded against the study description, and when they disagree it puts a red border alert on the notification box. Optionally, it goes one step further and tries to repair it: it types the study description into Mosaic's Study field so Mosaic swaps in the right template.

How to turn it on / set it up

Settings → Alerts → Alert Triggers → Template mismatch turns on the alert. The sub-option Attempt to correct template enables the automatic fix. Both live under the same tab as the other alert triggers, and require the notification box to be enabled.

Using it

Open a study; if the template is wrong you'll see the red border immediately, before you've dictated anything into the wrong skeleton. With auto-correct on, most mismatches fix themselves without you touching anything — the study description lands in the Study field and Mosaic reloads the matching template.

Tips & gotchas

  • Matching is tolerant of combined and protocol studies: CT+CTA combinations and perfusion protocols are handled, and a "CT BRAIN PERFUSION CTA HEAD NECK" won't false-flag against "CTA Head and Neck with Perfusion".
  • Auto-correct types into Mosaic — if you're mid-keystroke elsewhere it waits its turn through the normal action queue, but expect a brief flicker in the Study field when it fires.
  • If a template persistently mismatches for a study description your site words unusually, leave the alert on but auto-correct off and fix those by hand.

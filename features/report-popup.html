Report Popup

An overlay that shows your report right after Process Report — click it to cycle from Changes highlighting to Rainbow correlation to Orphan (unmatched) findings.

What it does

After Process Report finishes, MosaicTools pops up the full report as an overlay so you can review it without leaving the images. The popup has three display modes that you cycle through by clicking anywhere on it:

  1. Changes — newly added text is highlighted in your chosen color, so you can instantly see what this Process Report pass actually changed.
  2. Rainbow — each impression point and its matching findings sentences share a color (see the Rainbow Mode page).
  3. Orphan findings — shows only the findings that are not represented in the impression, to catch things you meant to carry down.

How to turn it on / set it up

Settings → Report Display:

  • Show Report overlay after Process Report — the main toggle.
  • Highlight report changes — enables the Changes mode, with a color picker and a transparency slider (default light green at 30%).
  • Rainbow Mode (findings-impression correlation) and Unmatched Findings (highlight findings missing from impression) — add the other two click-cycle modes.
  • Transparent overlay (see image through report) — renders the popup with a semi-transparent background so the radiology image shows through; a Transparency slider controls how see-through it is.
  • Show delete buttons on impression points — adds trash icons next to numbered impression points; click one to remove that point, and the edited impression pastes back into Mosaic about a second later.

You can also summon the same popup on demand with the Show Report action (map it under Keys & Buttons).

Tips & gotchas

  • The delete buttons on impression points require opaque mode — they are unavailable while the transparent overlay is on.
  • Only modes you've enabled appear in the click cycle; with everything on it goes Changes → Rainbow → Orphan and back.

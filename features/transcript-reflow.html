Riesz'ed up Transcript

Reflows the live report every few seconds so each sentence sits on its own line, separated by a blank line, for easier scanning — without moving your cursor.

What it does

When on, MosaicTools tidies the live report about every few seconds so each sentence sits on its own line, with a blank line between sentences (double-spaced) — so a wall of run-on text becomes easy to scan while you read and dictate. It only touches run-on paragraphs; a report already laid out one-sentence-per-line is left alone.

How to turn it on / set it up

Settings → Report Display → "Riesz'ed up Transcript (one sentence per line)." Off by default. Requires CDP (the direct-DOM connection to Mosaic); works on classic Mosaic's report editor.

Using it

Just dictate. As sentences land, the report reflows itself in the background. Your cursor stays put — the split is applied through the editor's own transaction, which maps the caret through the change, so you never get bounced to a different spot.

Tips & gotchas

  • Pause-safe: it won't reflow while your caret is mid-word (i.e. while you're actively typing/dictating into a word) — it waits for a natural break.
  • Idempotent: once each sentence is its own line it stops — it won't keep adding blank lines or re-splitting.
  • Sentence detection is radiology-aware: it doesn't break on decimals ("1.8 cm"), numbered list markers ("1."), or common abbreviations.
  • If it looks like it's "doing nothing," check the toggle is on — and note that a report already formatted one-sentence-per-line has nothing to reflow.

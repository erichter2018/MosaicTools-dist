Stroke Detection

Flags stroke studies with a purple alert the moment they open, and can create the Clario communication note for you — on a click, or automatically when you press Process Report.

What it does

Watches each study as it opens and shows a purple border alert on the notification box when it looks like a stroke case. From there it can handle the Clario communication note for you: click the alert to create it, or let MosaicTools create it automatically when you press Process Report.

How to turn it on / set it up

In Settings → Alerts, under Alert Triggers:

  1. Check Stroke detection (purple border).
  2. Optional: Also use clinical history keywords — in addition to the study description, the clinical history is checked against a keyword list. Click Edit... to customize the keywords (one per line).
  3. Choose how the note gets created:
    • Click alert to create Clario note — clicking the purple alert creates the communication note.
    • Auto-create Clario note on Process Report — the note is created automatically when you process a stroke study's report.

Using it

Open a stroke study, see the purple border, read the case. If auto-create is on, pressing Process Report files the Clario note without any extra step, and the study lands in the critical-studies tracker.

Tips & gotchas

  • The auto-note only fires on a manual Process Report (since 5.5.1) — never on the automatic processing that runs shortly after a drafted study opens. You won't get a stroke note filed before you've even looked at the images.
  • If you already created a Negative Critical on the study (documenting a negative stroke read), the automatic positive stroke note is suppressed.
  • Detection is keyword-based, so tune the keyword list to your practice's history phrasing ("code stroke", "CVA", "tPA", etc.) if you see misses or false alerts.
  • Requires the notification box scraping to be running (Settings → Behavior → Scrape Mosaic).

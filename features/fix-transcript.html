Fix Transcript

A mappable action that presses Mosaic's transcript-cleanup button (the wrench icon) for you — no mousing to the Transcript toolbar.

What it does

Mosaic's Transcript editor has a cleanup button — the wrench-in-a-circle icon — that tidies the dictated transcript. Fix Transcript is a MosaicTools action that clicks it for you, so you can trigger the cleanup from a PowerMic/SpeechMike button or a keyboard hotkey without leaving the images or hunting for the icon.

How to turn it on / set it up

Nothing to enable — just map it. Open Settings → Keys & Buttons and bind Fix Transcript to a spare mic button or hotkey, like any other action.

Using it

After dictating a chunk, hit the mapped button; MosaicTools finds the wrench in the Transcript editor toolbar and presses it. The transcript cleans up exactly as if you had clicked it yourself — this action adds convenience, not a different cleanup.

Tips & gotchas

  • The action drives Mosaic's own cleanup — what it fixes (and doesn't) is Mosaic's behavior, identical to a manual click on the wrench.
  • It works through MosaicTools' direct Mosaic access (CDP); if the button can't be found — say, no transcript is open — the action logs it and does nothing rather than clicking blindly.
  • It pairs well with a dictation-heavy workflow: dictate, Fix Transcript, then Process Report, all from mic buttons without touching the mouse.

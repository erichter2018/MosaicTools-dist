Settings Window

One settings window for everything — sidebar navigation by topic, a live search box that filters every option, and full backup/restore of your configuration.

What it does

All of MosaicTools' configuration lives in a single dark-themed window with a sidebar of sections: Profile, Desktop Mode, Keys & Buttons, Text & Templates, Alerts, Report Display, Behavior, TBWU & Metrics, Speech-to-Text, Summarize Prior, MTRec, Experimental, and Reference. Nothing is buried in config files — every option is a labeled control with a tooltip.

How to turn it on / set it up

Open it by clicking the widget-bar title, right-click → Settings, or double-clicking the tray icon. Changes apply when you save; some (like the diagnostics opt-in) apply live.

Using it

  • Search: the Search settings... box at the top filters sections and options as you type, including hidden alias terms ("autostart", "mic gain calibrator"), so you don't need to know which tab something lives on.
  • 🆕 What's New (top bar): opens the full scrollable version history — every release's notes, not just the latest.
  • Tooltips: hover any control for an explanation. Turn them off with Show tooltips throughout settings in Profile if you find them noisy.
  • Backup / Restore: right-click the widget bar → Backup Settings saves your entire configuration (mappings, macros, pick lists, templates, STT setup) to a .backup file; Restore Settings loads one and reloads the app. Settings are stored as JSON in %LOCALAPPDATA%\MosaicTools\.

Tips & gotchas

  • Back up before big experiments and before moving to a new workstation — restoring the backup on the new box carries everything over.
  • Sub-editors (Macro Editor, Pick List Editor, Impression Fixer editor, Key Mappings, Button Studio) open as their own windows from their sections and save independently.
  • If Settings won't open at all on a locked-down PC, it's usually the Windows RichEdit component failing to load — see the error dialog's guidance, or reinstall to a local (non-synced) folder.

CDP Integration

External Mosaic CDP is obsolete and defaults off. Core report actions use Windows accessibility when CDP is unavailable; Clario CDP is configured separately.

External Mosaic CDP is off by default

Recent regular Mosaic versions no longer provide the external CDP connection. MosaicTools now defaults it off and turns off previously automatic-on configurations once. Simple Mode does not switch it back on. You do not need to keep restarting Mosaic to dismiss an unavailable-CDP warning.

The manual Use external CDP (obsolete) option remains for an environment that explicitly supports it. Turning it on cannot restore access that Mosaic no longer exposes. Settings saved after the one-time migration keep your explicit choice.

Working without CDP

MosaicTools uses Windows accessibility for report and transcript reads and supported actions. Get Prior, macros, Process Report, MTRec, DLP and CC target the intended current-study editor. If the editor cannot be identified or a write cannot be confirmed, the action pauses or reports the problem instead of pasting into another field.

This does not restore every feature that previously injected content or styling into Mosaic. Independent column scrolling only works where Mosaic exposes a suitable field-level accessibility scroller. A report that cannot be read is not evidence that it is ready to sign; review the native report.

Clario CDP is separate

The Clario connection has its own Use CDP for Clario interaction setting, URL and Setup Chrome CDP Shortcut. Its configuration is not changed by the Mosaic CDP default. Launch Clario from the configured shortcut when using its CDP features. An unavailable Mosaic CDP connection does not by itself mean Clario needs reconfiguration.

Impression Popup

A small floating window that shows just the IMPRESSION after Process Report, so you can verify the conclusion without scrolling the report.

What it does

After Process Report, this floating window displays the IMPRESSION section by itself — the part you actually need to sanity-check before signing. It appears automatically once the impression is generated and hides itself when you sign the report, so it tracks your normal rhythm: process, glance at the impression, sign.

How to turn it on / set it up

Settings → Report Display → check Show Impression popup after Process Report. That's it — no action mapping needed.

Like the report popup, it supports two rendering styles: a solid dark window, or a transparent layered mode where the image shows through behind the text. It shares the Report Display transparency settings.

Using it

  • The popup appears near your images after each Process Report and updates for each new study.
  • Click it to dismiss it for the current case; it auto-hides when you sign.
  • Drag it wherever you like — it's a floating always-on-top window.

Tips & gotchas

  • If you want the whole report (not just the impression) with change/correlation highlighting, use the Report Popup instead — the two can run together, but most people pick one.
  • The popup is a display of the impression; to edit it, either dictate/edit in Mosaic as usual, or use the report popup's delete buttons on impression points (Settings → Report Display → "Show delete buttons on impression points").
  • Pairs well with the Findings/Impression mismatch alert (Settings → Alerts) — the popup gives you the impression to read, the alert flags a contradiction you might have missed.

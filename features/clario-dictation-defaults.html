Auto-fix Clario Dictation Defaults

Sets every site's Default Dictation in Clario to "mosaic 2", so a site that was just added for you - and set to the wrong dictation system - still starts dictation.

What it does

When you are credentialed at a new site, the site is added to your Clario account. Often it gets the wrong dictation system - the old "mosaic" instead of "mosaic 2" - and dictation will not start on that site's studies. It usually takes a few IT calls before anyone finds the cause.

With this setting on, MosaicTools checks your Clario Profile Management → Application Defaults list at startup and every 6 hours. Any site whose Default Dictation is not "mosaic 2" is changed to "mosaic 2". Sites set to MosaicC are left alone. The viewer column is never touched.

How to turn it on

  1. Clario CDP must work: Use CDP for Clario interaction on, and Clario opened from the "Clario CDP" shortcut (see CDP Integration).
  2. Check Auto-fix Clario dictation defaults to "mosaic 2" in the same Clario CDP section. It is off by default.

Using it

Nothing to do. When it changes a site you see a toast, for example Clario: set dictation default to "mosaic 2" for 1 site(s): .... If nothing needs changing, nothing is shown.

Tips & gotchas

  • Clario must be visible on a screen. A minimized Clario window is so slowed down by the browser that MT skips it and tries again 5 minutes later.
  • MT reads the list back after saving and reports only the sites that really changed. A site that has no "mosaic 2" choice at all is left as it is.
  • If you have unsaved edits open in that Clario table, MT waits.
  • It changes your own Clario profile only - the same change you could make by hand in Profile Management.

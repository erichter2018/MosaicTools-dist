Transcript Comparison

A line-by-line view of the merged ensemble transcript with each engine's raw transcript underneath it — see exactly who heard what.

What it does

When a dictated phrase comes out wrong, the first question is: did every engine mishear it, or did the merge pick the wrong voter? The transcript comparison popup answers that at a glance. It groups the dictation line by line — each ensemble (merged) line shown with the corresponding line from the driver and each secondary directly underneath, in a monospace font with color-coded engine prefixes. Differences between what an engine heard and what the ensemble shipped jump out immediately.

How to turn it on / set it up

It's opened from the live ensemble metrics popup (Settings → Speech-to-Text → Ensemble Mode → Show live metrics popup), which has a control to pop out the full comparison for the current or last dictation. No separate setting.

Using it

Typical use is forensic: you notice "anasarca" pasted as something odd, open the comparison, and see that two engines heard it correctly while the driver garbled it — or that every engine garbled it, meaning the audio itself (mic, distance, competing noise) is the problem. The window is resizable, scrollable, and remembers its size and position between uses.

Tips & gotchas

  • The columns follow your configured slots — whatever engine you've chosen as driver anchors the view.
  • If one engine's line is consistently empty, that engine isn't producing finals — check the ensemble health drawer for the reason.
  • This shows raw per-engine text before text processing; small formatting differences from the pasted report (units, punctuation) are expected and not errors.

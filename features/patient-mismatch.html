Patient Mismatch Alert

Pulsing yellow alert when InteleViewer is showing a different patient than the one open in Mosaic — the classic setup for dictating one patient's images into another's report.

What it does

The highest-stakes desynchronization on a PACS workstation is images and report belonging to two different people. MosaicTools continuously compares the patient name in Mosaic against the topmost InteleViewer window, and when they disagree the notification box gets a pulsing yellow border. It's the first-listed alert trigger for a reason.

How to turn it on / set it up

Settings → Alerts → Alert Triggers → Patient mismatch. Requires the notification box to be enabled (Enable Notification Box on the same tab); the alert shows even in alerts-only mode.

Using it

It runs in the background off the normal scrape loop — you only see it when Mosaic and InteleViewer diverge. That legitimately happens for a moment whenever you advance one application before the other, so the useful signal is a pulse that persists: if the yellow border is still going once both apps have settled, stop and reconcile which patient you're actually reading before dictating another word.

Tips & gotchas

  • Brief pulses during study transitions are normal and expected; they clear on their own as the two applications catch up.
  • Name comparison is deliberately tolerant of formatting differences between the two systems, and false alerts were further tightened in 5.4.5 — a persistent alert deserves attention.
  • It compares against the topmost InteleViewer window; with multiple InteleViewer windows open, make sure the one on top is the one you're reading from.
  • This alert is about the viewer/reporter pair. Wrong-sex content already inside the report is the Gender check's job.

Simple Mode

The starter profile a new install begins in — a working set already switched on, advanced features out of the way, and a settings screen scoped to what a first shift actually needs.

What it does

MosaicTools has 848 settings controls across 21 sections. The harder problem was the opposite shape: 133 of 205 toggles ship off, including the clinical history box, the recording indicator, warn-before-signing and every mismatch check. So a brand new install was simultaneously overwhelming and did almost nothing.

Simple Mode is a profile, not a filter. It switches a starter set on, switches advanced features off, and hides the rest. Hiding alone would have left a tidy settings screen in front of an app that still did nothing.

Switched on for you: the clinical history box (with age and sex added automatically), the recording indicator, auto-stop dictation on Process Report, and the four safety checks — patient mismatch, template mismatch, sex check, and warn before signing an unprocessed report.

Kept out of the way: the custom speech ensemble, macros and pick lists, MTRec's differential, prior summaries, the third-party integrations, and the productivity metrics.

Settings shows 6 sections instead of 21 — you, your microphone, the safety checks, the patient info box, what happens when a study opens, and the drafting popup.

How to turn it on / set it up

A first install turns it on by itself, before the first window appears, so MosaicTools does something useful on your very first study rather than waiting to be configured. The Setup Guide then walks you through the same set.

Toggle it any time from the widget bar right-click menu (or the tray icon) → Simple Mode.

Using it

  • Nothing is thrown away. Your macros, pick lists, templates, hotkeys and dictation setup are all still there — Simple Mode only switches features off and hides controls.
  • Leaving it puts everything back. MosaicTools takes a snapshot of every setting it changed on the way in, so switching Simple Mode off restores exactly what you had, not a set of defaults.
  • The settings window rebuilds when you toggle, so the sections appear and disappear the moment you reopen it.
  • The widget bar is trimmed too — the TBWU figure, the ensemble health light and the critical-notes counter are readouts for features Simple Mode switches off, and a dead indicator invites a support question. They come back with the rest.

Tips & gotchas

  • Two things are deliberately forced on and never shown: Mosaic CDP (how MosaicTools reads Mosaic at all) and the clinical-history fixers. They are how the app works, not choices worth putting in front of someone on their first shift.
  • The drafted findings popup is offered but starts off. It is shown rather than hidden so you can switch it on and see what it does when you are ready.
  • Simple Mode never touches auto-update — a radiologist who silently stopped receiving updates would have no way to notice.
  • Everything Simple Mode shows you, the Setup Guide also asks about. That is asserted by a test, so the two cannot drift apart.

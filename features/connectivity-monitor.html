Connectivity Monitor in development — not functional yet

Four tiny status dots on the bar — Mirth, Mosaic, Clario, InteleViewer — so when things feel slow you can see in one glance whether it's the network or you. In development — not functional yet.

⚠️ In development. This feature is not functional yet — the toggle exists in Settings but the monitoring is still being built and validated. Don't rely on the dots; this page describes the intended behavior.

What it does

Periodically checks reachability of the four servers your reading workflow depends on and shows the results as a 2×2 grid of colored dots on the widget bar: Mirth, Mosaic on the top row, Clario, InteleViewer on the bottom. Green is healthy; amber/orange/red indicate slow, degraded, or offline; gray is unknown. Clicking the dots opens a details window with per-server status.

How to turn it on / set it up

In Settings → Experimental → Network Monitor:

  1. Check Show connectivity status dots.
  2. Optionally tune Check every (10–120 sec, default 30) and Timeout (1–10 sec, default 5).

Using it

Ignore it until something feels wrong. Dictation lagging, worklist frozen, priors not loading? Glance at the dots: all green means the servers answer and the problem is elsewhere (Mosaic itself, your session); a red dot names the culprit before you've opened a ticket. Click for the details popup with each server's current state.

Tips & gotchas

  • This is a reachability check, not an application health check — a server can answer pings while its application layer is struggling. Treat green as "network path is fine", not "everything is fine".
  • It lives under Experimental deliberately; the interval and timeout are conservative so the checks themselves never load the network.
  • Remote/VPN readers get the most value: a flapping VPN shows up as synchronized dot changes across all four servers.

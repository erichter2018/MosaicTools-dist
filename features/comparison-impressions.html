Comparison Impressions

A separate window listing this study's comparisons by date — click a date to read that prior's IMPRESSION, with the most recent one shown first. Read-only; it never writes to your report.

What it is

The comparison studies' impressions, in a window of their own. The top line is the comparisons as dates, and clicking one shows that study's IMPRESSION underneath. The most recent is shown when the window opens, because that is the one you usually want.

A prior with no impression on file says so in plain words. It never shows an empty box and leaves you wondering whether the study has nothing or MosaicTools is broken.

Off by default. Turn it on in Settings → Drafting → Show impression for comparisons.

It never writes to your report

This is the difference between this window and the impression list inside the drafting popup. That one edits your report — delete a point, drag to reorder — which is why it is off by default and carries a warning. This window only ever displays a prior study's text. There is no path from it back into the editor.

Where the list comes from

The COMPARISON: line of the report you are dictating. Whatever put that line there — Get Prior, the Clario auto-comparison, or the InteleViewer study-list scan — this window reads the same line, so it can never disagree with what your report says. It refreshes if the line changes while you work.

Each date is then matched to the exam in Clario and that report's impression is pulled in.

When it shows nothing for a date

Two cases, both deliberate:

  • Clario has no record of that prior. Its list only holds what came through Clario, while InteleViewer shows the whole PACS history including outside studies.
  • Two studies share that date and the comparison text does not say which one is meant. Rather than guess, it shows nothing. The rule is the same one the comparison line itself follows: a wrong prior is worse than no prior.

Unnumbered lines under a numbered impression 6.0.8

A numbered prior impression is often followed by something nobody numbered — most often a communication record: "A Document Only Red message has been communicated to the Ordering Provider or Designee via the Reading Provider on 7/8/2025 4:50 PM MST, Message ID 6864152." It is not a finding, and it was routinely the longest thing in a window meant to be read at a glance.

When the impression is numbered, only the numbered points are shown.

A wrapped point is not an unnumbered one. A point that runs onto a second line keeps that line — the window only cuts where the point before it actually finished. An impression with no numbering at all is shown exactly as it was written, and so is anything above the first number.

The window itself

Same handling as the drafting popup, so the two behave alike side by side:

  • drag it by the handle at the top
  • resize it by either edge
  • its position and size are remembered per study type, so CT and XR can each sit where they suit you

It closes when you sign or discard the study.

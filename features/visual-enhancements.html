Visual Report Enhancements

Restyles the Mosaic report editor via CDP — Carolina-blue change tracking, inline subsection headers, and a size hierarchy that makes the report easier to scan.

What it does

With CDP access to Mosaic's report editor, MosaicTools can restyle the Final Report as you work:

  • Carolina blue change-tracking highlight — a calmer, more readable color for changed text than the default.
  • Inline subsection headers — section headers flow inline with their paragraph instead of consuming their own line, so more report fits on screen and the FINDINGS section reads like prose grouped by organ.
  • Slightly smaller content text — headers stay prominent while body text steps down a notch, giving the report a visual hierarchy instead of a wall of same-size text.

Nothing about the report's actual content changes — this is styling applied inside the editor, and the signed report is unaffected.

How to turn it on / set it up

  1. Settings → Experimental → check Use CDP for Mosaic interaction (a Mosaic restart is needed on first enable).
  2. Then check Visual report enhancements underneath it.

Using it

Once on, the styling applies automatically whenever a report is open. It re-applies itself after Mosaic re-renders, so it survives study changes and page reloads.

Tips & gotchas

  • This lives under Experimental for a reason: it restyles a UI MosaicTools doesn't own, so a Mosaic update can occasionally change how it looks until MosaicTools catches up.
  • Pairs naturally with Independent column scrolling and the in-editor highlight modes (No Highlight / Regular / Rainbow) — all part of the same CDP toolbox.
  • Related nearby toggles in the same settings group: Hide report drag/delete handles (removes the drag-to-reorder and delete icons on paragraphs) and Auto-scroll to cursor during dictation.

MTRec Boxes

After Process Report, small clickable boxes appear next to "Final Report" — green "+" boxes insert a guideline recommendation into the impression with one click, amber "⚠" boxes are association reminders.

What it does

Instead of pressing the MTRec key and having recommendations merge immediately, the boxes give you a look-then-click flow. After you Process Report, once the impression has generated, MTRec runs automatically and posts its results as small boxes next to "Final Report" (e.g. "+ renal"):

  • Green boxes are available recommendations. Click one and it's inserted into the impression; nothing is inserted until you click, and Ctrl+Z undoes an insert.
  • Amber boxes are association reminders (only if MTRec Associations is enabled). Hover to see which companion findings the report hasn't addressed; click to open the full checklist modal.

How to turn it on / set it up

Settings → MTRec → "Show MTRec boxes after Process Report" — on by default once the MTRec engine itself is enabled. The manual MTRec Recommendations key keeps working exactly as before and is unaffected by this toggle.

Keep boxes current as you dictate (new in 5.5.10): Settings → MTRec → "Keep recommendations up to date as the report changes" — on by default. With this on, MTRec doesn't only run after the Process Report action — it recomputes and refreshes the boxes whenever the Final Report changes and settles. So the boxes appear and stay current even when you process the report directly in Mosaic (no MosaicTools Process Report action needed). It only shows boxes — it never auto-inserts — so the Process Report action remains the way to insert everything at once.

Auto-insert (new in 5.5.5): a separate peer toggle, Settings → MTRec → "Automatically insert recommendations on Process Report", skips the click entirely — MTRec's green-box recommendations are merged into the impression automatically when you Process Report. It's independent of showing the boxes (you can have either, both, or neither), off by default, and Ctrl+Z still undoes an insert.

Using it

Process the report, glance right of "Final Report". No boxes = MTRec found nothing actionable. A green "+ thyroid" means a guideline follow-up is one click away; click it, check the wording in the impression, move on. An amber "⚠ cirrhosis" is a nudge, not text — hover for the missing companions or click for the checklist.

Debug information

Since 5.5.8 the box debug is always on — no setting required.

  • Hover a box to see the recommendation, a divider, and the exact dictated text it was based on — so you can tell at a glance why MTRec fired. For an AAST injury grade, it also names which finding set the grade (e.g. "grade II driver: 3 rib fractures (≥3)").
  • Right-click any box to copy the full, de-identified MTRec debug for the whole study to the clipboard (a small "debug copied" note pops up). Left-click still inserts as normal. The copied debug includes the entire dictation (every section, de-identified) plus an Associations section — each triggered checklist with the sentence that fired it and which companion findings were already addressed versus still to look for.

This replaces the old standalone "Copy MTRec Debug" action — the same information now lives on the boxes.

Settings → MTRec → "Include debug information on the boxes" now governs only the extra dev-diagnostic bits: the neutral "no MTRec actionable items" box (shown when MTRec ran but found nothing, so you're never left wondering whether it ran) and verbose per-run logging. The per-box "why" above is on regardless.

Tips & gotchas

  • The boxes wait for the impression to generate — on a slow processing pass they appear a beat after the report does.
  • Since 5.5.3 the boxes anchor correctly in the stacked (top/bottom) layout too, not just side-by-side.
  • Box labels are displayed all-lowercase (as are the tooltips and checklist) — that's cosmetic, since 5.5.0.
  • Clicking green inserts exactly what the manual MTRec key would have inserted for that finding, citation included.
  • Since 5.5.5, bilateral and multiple lesions each get a recommendation — adrenal, thyroid, liver, lymph node, and pancreatic findings no longer report only the first lesion; same-management lesions combine into one line, different work-ups stay separate.
  • Since 5.5.10, if you insert a recommendation and then the finding changes (e.g. you re-measure a nodule so a different follow-up applies), MTRec shows a "↻ update" box so your impression doesn't keep an out-of-date recommendation — click it to replace the old line with the current one. And when a finding is removed, its box clears on its own rather than lingering.
  • Fixed in 5.6.0: an abdominal aortic aneurysm is now sized by its maximal diameter, never its craniocaudal length — a report giving "…7 cm in length … 4.96 x 4.7 cm" previously read as a 7 cm aneurysm (over-recommending surgical referral) and now correctly uses the 4.96 cm diameter with the matching surveillance recommendation.

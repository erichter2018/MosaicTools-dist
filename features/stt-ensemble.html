STT Ensemble

Runs several speech engines on the same audio at once and merges them by word-level voting — engines correct each other, so the pasted text is better than any single engine alone.

What it does

Every engine mishears differently. The ensemble streams your dictation to up to seven voting engines at once: a Driver (the anchor — a streaming engine that produces the live transcript) and up to six Secondaries that vote on it word by word. Where the driver is confident and the others agree, the word stands; where they disagree, consensus wins. Corrections happen two ways: live, as you dictate, and by back-patch — a slower engine's final result arriving seconds later is folded back into text already pasted, so late evidence still counts. There are also non-voting observer slots that run alongside purely for comparison and never touch your report (currently a developer-only evaluation tool — regular installs won't see them).

How to turn it on / set it up

Settings → Speech-to-Text → Ensemble Mode → Enable Ensemble Mode. Pick the Driver and Secondary 1–6 engines (each slot has a Test button to validate its saved key). The easiest path is the Quick Setup Wizard, which fills the slots with the current Recommended Ensemble from whatever engines you have keys for. Merge wait (ms) and Correct below (%) tune how long the merge waits for voters and the confidence threshold below which the driver gets corrected — the defaults are fine.

Using it

Nothing changes at the microphone. You'll occasionally see a word snap to a better one a beat after it pasted — that's a back-patch landing.

Tips & gotchas

  • Every voting slot needs its own working (paid) API key except medASR, which is free and local.
  • Batch engines (Voxtral, Soniox Async, gpt-4o-transcribe) can't drive — the Driver must stream.
  • A guard prevents late corrections from re-inserting sentences already in your report.

Updated in 5.9.2

A new voter is available — OpenAI GPT Transcribe, reached through OpenRouter. On our own radiology recordings it is roughly twice as accurate as the older OpenAI engine, and it does not invent speech during silence.

The recommendation logic behind the ensemble was also corrected so it can no longer seat two AssemblyAI engines together. Two engines that hear alike do not provide two independent opinions, and when they agreed on a mistake they could outvote the driver.

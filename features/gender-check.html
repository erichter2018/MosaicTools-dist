Gender Check

Flashing red alert when the report contains gender-specific terms that don't fit the patient — a prostate in a female patient's report, a uterus in a male's.

What it does

A gender-specific organ in the wrong patient's report almost always means one of two things: a template with leftover organ lines, or dictation landing in the wrong chart. Either way you want to know before signing. Gender check watches the drafted report for gender-specific terms that contradict the patient's sex and raises a flashing red border on the notification box when it finds one.

How to turn it on / set it up

Settings → Alerts → Alert Triggers → Gender check. Like the other alert triggers it needs the notification box enabled (Enable Notification Box, same tab) and fires even in alerts-only mode.

Using it

Nothing to do during a normal case — it's silent until it trips. When it does, the notification box flashes red, and with the CDP connection active the offending text also flashes red inside the report editor itself until you correct it, so the exact word is easy to find in a long report.

Tips & gotchas

  • The most common trigger is benign: a stock template mentioning the uterus/prostate in its normal lines on a mismatched patient. It's still worth the two seconds to check — the rare true wrong-patient case looks identical.
  • It reads the patient's sex from the scraped study data, so it needs background Mosaic scraping running (it is by default).
  • Pair it with the Patient mismatch alert: gender check catches wrong-sex content inside the report, patient mismatch catches Mosaic and InteleViewer showing two different patients.

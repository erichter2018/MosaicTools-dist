Headless Mode

Launch with -headless and MosaicTools runs invisibly from the system tray — no widget bar, no hotkeys, but your mic buttons and toasts still work.

What it does

Headless mode strips MosaicTools down to the invisible essentials for people who want the automation without any on-screen chrome. There's no widget bar and no global keyboard hotkeys — just a system-tray icon. PowerMic/SpeechMike buttons, the InteleViewer floating toolbar, and toast notifications all still work, so every mic-triggered action behaves exactly as in normal mode.

How to turn it on / set it up

Start the exe with the flag:

MosaicTools.exe -headless

To make it permanent, add -headless to whatever launches MosaicTools (a shortcut's Target field, or your startup entry). The tray icon reads "Mosaic Tools (Headless)" so you can tell which mode you're in.

Using it

Everything runs from the tray icon:

  • Double-click it to open Settings.
  • Right-click for Settings, Show Log, and Exit.

Trigger actions with your mic buttons as usual. Toasts still appear at the bottom-right for feedback (action confirmations, warnings, update notices).

Tips & gotchas

  • Keyboard hotkeys are intentionally disabled in this mode — if you rely on hotkeys rather than mic buttons, headless isn't for you.
  • Bar-dependent displays (TBWU metrics, critical count badge, ensemble health dot, connectivity dots) have nowhere to render; the underlying services still run, you just don't see the indicators.
  • Settings are shared between modes — configure everything in normal mode first, then switch to headless once you're happy.
  • Desktop-only sections (like the recording indicator options) hide themselves in the Settings window when running headless.

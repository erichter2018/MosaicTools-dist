Graphical Ensemble Builder

A visual builder for your dictation ensemble — pick an anchor and voters, see the live word-error estimate and what it costs per dictated hour, add a missing key on the spot, and save.

What it does

The Graphical Ensemble Builder is a visual way to assemble or fine-tune your multi-engine dictation stack, keyed to the engines you actually have. It shows a streaming anchor row and a voters list; pick a combination and it estimates the resulting word-error rate live against our radiology test corpus. Engines you don't have a key for are greyed. Ready-made tiers sit at the top — Recommended for you (from the keys you already have), Best value (the most accuracy per dollar), Minimal-effort best (with easy one-key additions), and Very best possible (assuming you add every key) — and they come from the exact same recommendation engine as the Quick Setup wizard, so the two never disagree.

Every accuracy figure is a WER (word error rate) and every price is per hour of dictated audio, not per hour of shift — a radiologist who dictates 90 minutes across an eight-hour shift pays for 90 minutes.

How to turn it on / set it up

Settings → Speech-to-Text → 🎛️ Graphical Ensemble. It opens keyed to your current setup.

Using it

Click a tier to load it, or hand-build: choose an anchor, tick voters, and watch the word-error estimate update. Right-click a greyed engine to add its API key without leaving the builder — the moment it's keyed, it lights up. Save as my ensemble writes the configuration, turns on ensemble mode, and updates the slot picker. Anchors are limited to the strong streaming engines (Deepgram, AssemblyAI, Speechmatics) because the anchor is the merge spine — a weak anchor drags the whole ensemble down.

Tips & gotchas

  • The recommendation is the lowest word-error stack it can build, and it never puts two variants of the same engine in one ensemble (e.g. AssemblyAI streaming + AssemblyAI batch) — those are correlated and don't add a real second opinion.
  • The number you see is measured over the full radiology corpus — the same number the app uses internally, so what you pick is what you get.
  • Two setups can tie on accuracy at very different prices. When they tie, the cheaper one is ranked first and is the one chosen as "Best" — so the top of the list is never needlessly expensive. The Rankings and Models tabs both show cost per dictated hour beside the WER. (5.8.29)
  • Prices come from each vendor's published rate. A handful of models are billed by token rather than by audio, so those are measured across the corpus instead — the tooltip says which. (5.8.29)
  • You don't need to configure backups here: failover is automatic and draws on every engine you've set up (see Failover backups).

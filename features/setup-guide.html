Setup Guide

The first-run walkthrough — eleven short chapters in workflow order that explain each feature in plain language and set it up as you go, with your settings untouched until you press Apply.

What it does

Opens by itself the first time MosaicTools runs and walks you through the app in workflow order — set up, open a study, dictate, process, review, ship — rather than in the order the settings happen to be laid out. Each card explains one feature in plain language, says why it is suggested, and offers to switch it on.

How to turn it on / set it up

It runs itself on a genuine first install. After that, open it any time from Settings → Getting Started. If you dismiss it, MosaicTools offers it once more about a week later, then leaves you alone.

Using it

  • Your settings are untouched until you press Apply. Every choice is staged; the review screen at the end lists exactly what will change before anything is written.
  • Skip for now is remembered per question — the guide offers the skipped ones again next time you open it.
  • Your last name is required (6.0). It is what MosaicTools uses to tell you apart from the other doctor in a Clario note, so a note reading "Transferred Smith to Jones" knows which one is you. The field arrives holding the placeholder Radiologist, and the guide will not move past it until you replace it. Last name only, spelled the way Clario spells it — no first name, no initials, no "Dr".
  • Cards that ask for consent — diagnostics, audio contribution — always put the neutral choice on the primary button, so holding Enter through the guide can never opt you into anything.

Tips & gotchas

  • The guide covers every setting Simple Mode shows you, which is checked by a test rather than by memory — so a new setting cannot quietly appear in Simple Mode with no explanation behind it.
  • Chapters can be skipped whole, except where a chapter holds a required question: skipping lands you on that question instead of stepping past it.
  • The guide reads its feature descriptions from this documentation site, so the words here and the words in the wizard are the same words.

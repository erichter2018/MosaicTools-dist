Pick Lists

Structured text insertion from a popup — navigate a hierarchical tree or build sentences category-by-category, and paste the result straight into the report.

What it does

Presents a popup of your configured pick lists for the current study and pastes what you select. Two modes per list:

  • Tree — hierarchical navigation with breadcrumbs; drill into categories and pick items (structured or freeform accumulation).
  • Builder — sentence construction: step through categories in order (location → size → character…), and the popup assembles the sentence as you go.

Tree nodes can embed Builder lists and vice versa, so a tree item can drop you into a sentence builder mid-flow.

How to turn it on / set it up

  1. Check Enable Pick Lists in Settings → Text & Templates → Pick Lists.
  2. Click Edit... to create lists in the Pick List Editor — define each list's trigger criteria (study description), mode, and items. Items can also reference macros.
  3. Map the Show Pick Lists action to a button or hotkey in Settings → Keys & Buttons (the settings page reminds you: Assign "Show Pick Lists" action in Keys dialog).
  4. Options:
    • Skip list when only one matches — jumps straight into the list instead of showing a one-item chooser.
    • Keep window open — the popup stays up after inserting, so you can fire several items with the number keys.

Using it

Press the mapped button, pick with mouse, arrow keys, number keys, or the search box; the text pastes into the report at the cursor. In Builder mode, finish the sentence and it pastes as a unit; undo steps back one selection.

Tips & gotchas

  • Pick lists match on the study description, so a study matching zero lists shows nothing — check your trigger criteria if the popup seems empty.
  • Number keys are the fast path with Keep window open: press the digit, item inserts, popup stays.
  • Editing macros referenced by pick lists is safe — references are preserved by ID.
